# UnCaramba Switcher

Бесплатный open-source автопереключатель раскладки RU ↔ EN для macOS — аналог Punto Switcher и Caramba Switcher.

## Что умеет

- `ghbdtn` → `привет`, `руддщ` → `hello`
- исправляет опечатки: `пирвет` → `привет`, `незнаю` → `не знаю`, `вообщем` → `в общем`
- пунктуация и слитные слова: `привет1` → `привет!`, `пирогб` → `пирог,`, `почемуто` → `почему-то`
- ёфикатор: `еще` → `ещё`
- двойной Shift — отменить исправление (слово запомнится), одиночный Shift — сменить язык
- режимы для программ: авто / только вручную / выключено (терминалы и IDE — вручную по умолчанию)

## Как работает

Внутри частотная модель языка: ~1,1 млн русских и ~220 тыс. английских словоформ.
Частоты взяты из субтитров OpenSubtitles, остальные слова — из полного словаря с минимальной частотой; всё проверено словарём macOS.
После каждого слова программа сравнивает варианты (другая раскладка, исправление опечатки) и выбирает самый вероятный.
Если уверенности нет — слово не трогает.

## Установка

Скачай `UnCarambaSwitcher.dmg` из [Releases](../../releases), открой и перетащи приложение в «Программы».
Приложение не нотаризовано: при первом запуске — правый клик → «Открыть».
Дай доступ в «Настройки → Конфиденциальность и безопасность → Универсальный доступ» и «Мониторинг ввода».

## Сборка

```bash
./build.sh --install
```

Пересобрать модель (~10 минут): `tools/build_model.sh`.

Данные: [FrequencyWords](https://github.com/hermitdave/FrequencyWords) (OpenSubtitles), [russian-words](https://github.com/danakt/russian-words), [english-words](https://github.com/dwyl/english-words).
